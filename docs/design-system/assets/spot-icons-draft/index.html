Jenis latihan

Kartu latihan di Today dan Plan, hero detail aktivitas. Warna ubin mengikuti skala panas zona, jadi warna tetap punya arti.

Kartu Today

Kepala tiap kartu carousel: race, long run berikutnya, rekor, streak.

Rasa setelah latihan

Layar Selesai: tiga pilihan RPE (1-4, 5-7, 8-10) sebagai wajah, angka tetap tertulis.

Timer

Siap-siap, istirahat, pengaturan bunyi penanda, layar selesai.

Progress, profil, keadaan kosong

Ringkasan minggu, total jarak, privasi data, layar tanpa aktivitas, catatan cedera.

Badge pencapaian

Bentuk stadium tegak dengan pita. Muncul di ringkasan minggu dan profil (sebelumnya tercatat 'Belum ada').

Tangga ukuran

Wajah dan detail masih terbaca di 32 px. Di bawah 32 px pakai ikon garis 24 px.
