Ikon spot Run Coach

Ikon berwarna yang memberi wajah pada konten: jenis latihan, kartu Today, rasa setelah latihan, timer, progres dan pencapaian. 27 ikon sudah dipakai di app; 28 ikon baru di halaman ini masih usulan.

Jenis latihan

Warna ubin = skala panas zona, jadi warna tetap punya arti.

Jenis latihan tambahan

Untuk jenis yang sekarang masih meminjam ikon lain (progression, run-walk, strides, core).

Kartu Today

Kepala kartu geser 2.1.

Rasa setelah latihan

Wajah RPE: 1-4 ringan, 5-7 pas, 8-10 berat. Angka tetap tertulis.

Catatan latihan

Tag di 2.4 / 2.6: cuaca panas, kurang tidur, kaki pegal (ada nyeri memakai ikon cedera).

Timer

Siap-siap, istirahat, bunyi penanda, selesai.

Target

Pilihan target 1.2 dan baris Target di Profil.

Fase plan

Base, Build, Peak, Taper. Warna ubin = token fase.

Progres, privasi, keadaan kosong

Ringkasan minggu, total jarak, data di HP, belum ada aktivitas, cedera.

Jeda plan

Alasan jeda 4.3 (cedera memakai ikon cedera).

Pengaturan dan onboarding

Pengingat, backup, bahasa, panduan, Premium, zona, detak jantung, integrasi, cek kesehatan, hari latihan.

Badge pencapaian

Kartu Pencapaian di Progres (F-28).

Tangga ukuran

Detail dan wajah masih terbaca di 32 px. Di bawah 32 px pakai ikon garis 24 px.

Catatan

  • File SVG di docs/design-system/assets/spot-icons/, dibuat dari _build/spot_icons.py. Ikon baru belum masuk spot-icons.json app.
  • Semua warna dari token Lintas. Mode gelap: ubin pastel tetap, ubin strength memakai zone-strength gelap.
  • Angka di ikon target digambar sebagai garis (tanpa font), jadi tampil sama di semua perangkat.
  • Pengaturan dan chip memakai komponen yang sudah ada; ikon spot di sana mengubah gaya baris, jadi perlu keputusan dulu.
