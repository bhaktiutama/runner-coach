Animasi gerakan

Figur sederhana dari SVG yang digerakkan oleh data sudut sendi (pose keyframe). Satu format data dipakai untuk semua gerakan, sehingga bisa dirender ulang di app (react-native-svg) tanpa file video.

Prototipe. Dosis (set x repetisi) dan cue teknik adalah contoh dan perlu di-review pelatih atau fisioterapis sebelum dipakai di app. Kaki/lengan gelap = sisi dekat kamera, abu-abu = sisi jauh.
